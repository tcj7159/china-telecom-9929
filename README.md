## 9929 到底解决了什么

先把“骨干网”这件事说清楚。联通手里有好几个 AS 号，AS4837 是承载普通跨省和国际流量的骨干，AS9929 是定位更高的优化骨干，国际方向还常和联通国际的 AS10099 配合，商家宣传的“9929+10099”说的就是国内段走 9929、出海段走 10099 这个组合。

用一个不太精确但好用的比喻：4837 是高速公路主路，9929 是主路边上的快速通道。车多的时候快速通道还能动，主路已经开始排队。差别不在理论带宽，在拥堵时的表现。

对海外 VPS 来说，9929 有三种出现方式：去程走 9929、回程走 9929、双程都走。**回程更关键**，因为数据从海外回国内，如果被丢进普通骨干，很容易卡在中间某个互联节点上，前面去程再快也白搭。

丽萨主机对自家 9929 方案的描述是“三网回程优化”：电信用户回程走联通 9929 再到电信 163，联通用户直连 9929，移动用户走 9929 再到移动 CMI。翻译成人话就是，不管你家装的是哪家宽带，数据回国都会先挤上联通这条快速通道，再转回你自己的运营商。

### 这套优化能带来多少实际提升

一位北京联通用户公开记录过他的 9929 加速体验，数据挺具体：

- 上海出口可以直连东京 NTT，原本 150ms 的东京 NTT 在 9929 下变成 50ms；
- Cloudflare 可以直连香港，时延 70ms，比普通联通绕美国快很多；
- 洛杉矶 4837 直连往返 180～190ms 的机器，9929 能稳定在 150～160ms；
- 带宽不打折，原有家宽千兆下行照样跑满。

注意这是联通家宽的“海外宽带加速”业务，和 VPS 回程不是同一件事，但能说明 9929 这条路径本身的能力边界：**它改善的是路径，不是凭空造带宽。**

### 但它不是对所有网络都加速

同一份记录里也有负优化案例：一些本来 4837 直连美国 150ms 的机器，走 9929 后被绕到德国出口再去美国，变成 250ms；访问宁波电信会先走 9929 广州再回宁波，访问常州移动会先走 9929 上海、再到南京、再到常州。作者的结论是“比较鸡肋”，还补了一句“9929 不是对所有网络都加速”。

这句话值得所有准备下单的人抄下来。

一份针对荷兰阿姆斯特丹机房的公开路由测试更能说明问题。那台机器的回程经英国伦敦的联通 AS10099 节点进入中国，到上海、广州落地时能看到 AS9929 节点（218.105.131.126、218.105.131.146），再转电信 AS4134 或联通 AS4837 到目的地，北京电信全程约 155ms、上海电信约 177ms、深圳电信约 192ms。但同一台机器到北京联通、北京移动、成都教育网的回程，走的是 AS4837，压根没经过 AS9929。

所以“三网回程 9929”这种描述，在不同机房、不同运营商方向上会有出入。买之前最好自己 traceroute 一遍，看回国路径里有没有出现 AS9929 的节点，这比看宣传词靠谱。

## 9929、4837、CN2 GIA 怎么选

三条线的定位，一句话各自概括：

| 线路 | 定位 | 适合谁 |
| --- | --- | --- |
| AS9929 | 联通精品骨干，三网回程优化，晚高峰比普通线路稳 | 主要用户在中国大陆，预算中等，看重晚高峰体验 |
| AS4837 | 联通普通骨干，带宽大、价格低 | 白天业务为主、对峰值延迟不敏感、要大带宽大流量 |
| CN2 GIA | 电信高端线路，电信方向回程质量最极致 | 电信宽带用户，对延迟极度敏感，预算充足 |

几个具体判断：

**你是联通宽带用户**，9929 是这三条里最对口的，因为回程直连，不用转接。**你是电信用户**，9929 的体验接近 GIA 但便宜三到五成，除非你做的就是那种对 20ms 都斤斤计较的业务，否则没必要为 GIA 多付那份钱。**你是移动用户**，9929 走 9929→CMI 的路径，也够用。

**如果你的业务主要跑在白天**，比如自动化任务、备份、早上发的邮件营销，那 4837 的性价比更高。9929 的溢价买的就是晚高峰那三小时，你不在那个时段用，多花的钱就是白花。

**如果你的访客主要在海外**，9929 基本没有意义。国内优化对欧美用户不起作用，这时候该看的是机房位置和国际带宽，不是回程线路。

**9929 适合建站吗？**
适合。三网回程优化意味着国内访客延迟低、高峰期不丢包，对小站和博客的体验提升比对大站更明显。配合 48 小时无条件退款，可以先开一个月实测晚高峰再决定续不续。

**双 ISP 住宅 IP 和原生 IP 差在哪？**
原生 IP 指 IP 归属地就是机房所在地，不是广播过去的；双 ISP 住宅 IP 是在此基础上，IP 注册信息呈现为两家 ISP 的家庭宽带属性。后者在 TikTok、Instagram、亚马逊这类会查 IP 信誉的平台上，过审率和存活率通常更高。代价是价格，499 元/年和 299 元/年的差别主要就在这。

**支持 Windows 吗？**
支持，一期和二期都可以安装 Windows 系统。KVM 架构，自动开通。

**IP 被封了怎么办？**
这是所有机房 IP 的共同风险，9929 线路本身不解决这个问题。一份公开体验记录里也提到，“即使 9929 直连很快的机器，依然得面对固定 IP 被墙的风险”。资料里没有给出免费换 IP 的明确政策，下单前建议先开工单问清楚，别默认它能随便换。

**怎么验证买到的到底是不是真 9929？**
用 traceroute 或 mtr 跑一遍回程，看路径里有没有 AS9929 的节点（比如 218.105.x.x 这类）。前面提到的那份荷兰机房测试里，到上海和广州能看到 AS9929 节点，到北京联通、北京移动和成都教育网走的却是 AS4837。**同一台机器不同运营商路径可能不同，要逐条看**，别只测一条就下结论。

**年付还是月付？**
不确定就先月付或季付，实测晚高峰的延迟和解锁情况，满意了再转年付。年付折算下来确实便宜很多，但 9929 的实际体验和你在哪个省、用哪家宽带关系很大，别人的测评替代不了自己的实测。
